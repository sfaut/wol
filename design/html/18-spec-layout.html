ElementControlProperties and spacing

Title barTitleBarExtendsContentIntoTitleBar = true, height 48, IsPaneToggleButtonVisible = true, IsBackButtonVisible = false, icon 16, title “Wol” in CaptionTextBlockStyle.
NavigationNavigationViewPaneDisplayMode Auto, OpenPaneLength 280, CompactModeThresholdWidth 641, ExpandedModeThresholdWidth 960 (so 1000 opens Expanded), IsSettingsVisible = true, IsPaneToggleButtonVisible = false (toggle is in the TitleBar).
All machinesNavigationViewItemIcon FontIcon U+E71D AllApps.
Groups headerNavigationViewItemHeaderText “Groups”; hidden when there are no groups.
Group itemNavigationViewItem + InfoBadgeIcon U+E8B7 Folder. InfoBadge Value = Offline + Timed out count, Visibility Collapsed at 0. ContextFlyout = MenuFlyout (Wake group, Rename…, Move up, Move down, Delete group…). CanDrag for reorder; AllowDrop for machines.
UngroupedNavigationViewItemShown only when at least one machine has no group. Always last, not reorderable.
New groupNavigationViewItemIcon U+E710 Add, SelectsOnInvoked = false, opens the New group dialog (Ctrl+Shift+N).

Add / Edit machine

ElementControlProperties and spacing
DialogContentDialogRecommended over a page: short form, keeps list context. Title “Add machine” / “Edit machine”; PrimaryButtonText Add / Save; CloseButtonText Cancel; DefaultButton Primary; IsPrimaryButtonEnabled bound to form validity. Width 548.
BodyScrollViewer > StackPanelSpacing 16. Scrolls when Advanced is open or the window is short; buttons stay pinned.
Name, MAC, HostTextBoxHeader above (Body), Description below for help or the error (Caption). Validate on LostFocus and on submit; show the first error inline, never in a separate dialog.
MAC addressTextBoxAccepts AA:BB:CC:DD:EE:FF, AA-BB-…, AABBCC…, any case. Description previews the normalised value (“Will be saved as …”).
GroupComboBoxIsEditable = true, Header “Group (optional)”. TextSubmitted with an unknown name stages a new group; Description says “New group … will be created”.
AdvancedExpanderCollapsed by default. TextBox Broadcast address (PlaceholderText “Automatic”), CheckBox “If ping gets no reply, try TCP ports”, TextBox ports (enabled by the CheckBox, indent 28).
ValidationTextBlock in DescriptionError: FontIcon 14 U+EA39-style + text in SystemFillColorCriticalBrush, AutomationProperties.LiveSetting Assertive. Host not resolvable is a warning (SystemFillColorCautionBrush icon), not blocking.

Groups

ElementControlProperties and spacing
New / RenameContentDialog + TextBoxTitle “New group” / “Rename group”; Primary Create / Rename, disabled while the name is empty or already used; inline error under the TextBox.
Delete groupContentDialog + RadioButtonsTitle names the group. RadioButtons: “Move them to Ungrouped” (default), “Delete them too”. PrimaryButtonText “Delete group”, CloseButtonText Cancel, DefaultButton Close.
ReorderMenuFlyout + dragMove up / Move down (Alt+Up / Alt+Down) on the item’s ContextFlyout; drag in the pane as a shortcut. Order is saved immediately.
Move machinesMenuFlyoutSubItem“Move to group” lists groups in order, then Ungrouped, separator, “New group…”. The current group shows a check and is disabled.

Wake feedback

ElementControlProperties and spacing
Row while wakingProgressRing16 × 16, IsIndeterminate; detail text “m:ss · waiting for reply” updated every second.
Single resultInfoBarIn the notification host. Success: IsClosable, auto-close after 5 s (paused while hovered or focused). Warning (timed out): stays until closed, ActionButton Retry.
Group or selectionInfoBar + ProgressBarIsClosable false while running, Severity Informational, Content = ProgressBar (Maximum = machines in the run, Value = online). ActionButton Cancel. Replaced by the result InfoBar with “Retry n machines”.
Notification hostStackPanelBottom-aligned in the content grid, margins 36 / 32 / 16, Spacing 8, at most 3 bars, ChildrenTransitions: EntranceThemeTransition + RepositionThemeTransition.

Settings

ElementControlProperties and spacing
PageScrollViewer > StackPanelMaxWidth 1000, margins as the list page, Spacing 4 between cards; section headers BodyStrongTextBlockStyle, Margin 1, 24, 0, 6.
Theme, LanguageSettingsCard + ComboBoxTheme: Use system setting / Light / Dark (applies at once, sets RequestedTheme on the root). Language: Use system setting / English / Français (applies on restart; Description says so). ComboBox MinWidth 200.
BehaviorSettingsCard + ToggleSwitchStart with Windows (StartupTask, off by default), Start minimized (off), Close to the notification area (on).
MonitoringSettingsCard + NumberBoxCheck interval 5–3600 s (default 30), Wake timeout 30–900 s (default 120). SpinButtonPlacementMode Inline, SmallChange 5, LargeChange 30, Width 132, unit TextBlock after.
NotificationsSettingsExpanderHeader toggle = master switch. Items: SettingsCard with CheckBox per state (Comes online, Goes offline, Doesn’t wake up, Has an error); items disabled when the master is off.
AboutSettingsExpanderHeader: app icon, “Wol”, version, Copy button. Items: Companion CLI (version, path, status glyph + label, Check again), Configuration file (path, Open file location), HyperlinkButtons.

Notification area

ElementControlProperties and spacing
IconShell_NotifyIcon (Win32)Not a XAML control: hosted through a notify-icon helper. 16 × 16 monochrome .ico per status and taskbar theme; tooltip states the status in words (max 127 chars).
MenuMenuFlyoutOpen Wol (default item, bold), separator, MenuFlyoutSubItem Wake ▸ group ▸ “Wake all offline (n)” + offline machines, Refresh, separator, Quit.
BalloonsNOTIFYICONDATA NIF_INFOTitle + text only (NIIF_INFO, NIIF_WARNING for timed out). Title ≤ 63 chars, text ≤ 255. Respect the Notifications settings; skipped while the window is in the foreground — the in-window InfoBar covers it.

Errors and degraded states

ElementControlProperties and spacing
SlotInfoBarGrid row 0 of every page, Margin 36, 12, 32, 0, IsOpen bound to app state, IsClosable false. One bar at a time; precedence: CLI missing → CLI incompatible → configuration invalid → network unavailable.
CLI missingInfoBar ErrorActionButton “Locate…” (FileOpenPicker for the CLI executable) + HyperlinkButton “How to install”. Checks and wake disabled; editing still allowed.
CLI incompatibleInfoBar ErrorShows required and found versions; ActionButton “Check again”, HyperlinkButton “How to update”.
Configuration invalidInfoBar ErrorMessage includes line (and column) from the CLI. ActionButtons “Open file” and “Reload”. The last valid list stays visible, read-only.
Network unavailableInfoBar WarningDriven by NetworkInformation.NetworkStatusChanged; hides automatically when connectivity returns, then a full refresh runs.
